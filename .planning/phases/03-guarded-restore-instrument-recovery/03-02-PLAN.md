<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Two browser slot selections → swap POST | Two stale or identical targets could trigger an incorrect multi-target mutation. |
| Browser instrument cell/action → captured sample-pack grid | User-controlled type/slot/action data selects live removable-volume files. |
| Laptop Music/trash path → instrument import | A relative path or symlink could escape allowed roots or provide malformed AIFF bytes. |
| Mounted grid → laptop recovery/trash | Cross-volume copying must verify bytes before any live deletion. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-09 | Tampering | two-slot swap | high | mitigate | Capture both slots under one guard, verify two automatic backups before either write, compare both fingerprints plus the opaque source token, and verify both final/rollback Buffers; second-write failpoint is blocking. |
| T-03-10 | Spoofing | source and dynamic pack paths | high | mitigate | Pin canonical root/projects/samplepacks identity once and construct validated child paths beneath it; prohibit dynamic source/path helpers after guard entry and assert fallback untouched. |
| T-03-11 | Tampering | live instrument grid | high | mitigate | Publish/reclassify a complete deep recovery before any pack mutation and compare the exact full-grid manifest after change or rollback. |
| T-03-12 | Tampering / Elevation of Privilege | import path and AIFF bytes | high | mitigate | Canonical allowed-root containment, symlink/regular-file/extension checks, empty target, `packInfo()` validation, staged write, and exact reread; traversal/prefix/symlink/corrupt-input tests block. |
| T-03-13 | Tampering | remove/trash cross-volume copy | high | mitigate | Copy every selected file to a unique laptop trash directory, compare manifest and bytes before deletion, and retain the independent deep recovery archive. |
| T-03-14 | Information Disclosure | receipts and instrument errors | high | mitigate | Return only stable public operation facts and sanitized recovery IDs/states; exclude live/import/trash paths, temp names, device identity internals, stacks, and raw parser errors. |
| T-03-15 | Repudiation | UI mutation scope | medium | mitigate | Exact swap/instrument confirmations, one busy/result region, visible retained recovery IDs, focused alerts, and text labels communicate scope independently of color. |
| T-03-16 | Elevation of Privilege | op1.fun install | high | mitigate | Keep `/api/op1fun/download` in the central unavailable inventory and its browser install control disabled; authenticated upstream response/redirect validation is outside this phase. |
| T-03-SC | Tampering | package supply chain | low | accept | No install task or third-party code is introduced; existing Node/browser built-ins and parsers cover the slice. |
</threat_model>
