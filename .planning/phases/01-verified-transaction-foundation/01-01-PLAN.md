Existing source contract: `getSource()` returns `{root, path, device, label}` and may fall back to `opzdisk/`; call it only at capture time.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → localhost API | User-controlled JSON, headers, and cross-site browser requests reach state-changing routes. |
| Node process → removable OP-Z/local fixture | A source can disappear, be replaced, or change after capture. |
| Captured memory → laptop library | A partial/corrupt staged write must not become a visible verified archive. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering | `captureSource` / `assertCapturedSource` | high | mitigate | Pin canonical root, filesystem identity, project identity, and Buffer; revalidate directly and never re-resolve after capture. |
| T-01-02 | Tampering / Repudiation | `archiveCapturedProject` | high | mitigate | Hidden same-parent draft, flushed write, stored-byte reread/equality, parser check, SHA-256/length evidence, then atomic rename. |
| T-01-03 | Tampering | `/api/backup` input | high | mitigate | Validate slot/type/boolean/name before any derived path or filesystem access. |
| T-01-04 | Tampering / Denial of Service | `withMutation` | high | mitigate | One global reject-not-queue guard is acquired before source resolution/capture, held through awaited completion, and released in `finally`. |
| T-01-05 | Spoofing / Tampering | localhost POST | medium | mitigate | Require JSON plus `X-OPZ-Mutation` on archive POST; Plan 01-02 applies Origin/Fetch-Metadata policy to every POST. |
| T-01-06 | Information Disclosure | API/state errors | medium | mitigate | Stable codes and source-kind guidance only; omit resolved paths, stacks, and settings values. |
</threat_model>
