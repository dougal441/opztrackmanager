## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser/CLI → localhost API | Untrusted method, headers, origin metadata, JSON types, identifiers, and paths enter mutation routes. |
| Route dispatcher → filesystem helpers | A route could bypass the shared lock or pass an unpinned source into a helper. |
| Node process → library/device roots | Derived child paths and removable-media identity determine mutation targets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering | archive guard/capture ordering | high | mitigate | Acquire the global guard before invoking the callback that resolves and captures the source; conflict paths do zero source work. |
| T-01-02 | Tampering / Repudiation | archive eligibility | high | mitigate | `findBundle` accepts only visible, parsable bundles whose reread SHA-256/length match verification evidence. |
| T-01-03 | Tampering | validators / `resolveChild` | high | mitigate | Positive checks plus canonical root/child `realpathSync` and `path.relative` containment reject traversal and symlink escape before access. |
| T-01-04 | Tampering / Denial of Service | destructive route inventory | high | mitigate | Backup enters one awaited global guard before capture; unowned device-writing routes return `PHASE_UNAVAILABLE` before mutation. |
| T-01-05 | Spoofing / Tampering | `requireMutationRequest` | medium | mitigate | JSON plus custom header, Fetch Metadata rejection, and present-Origin/Host equality block simple cross-site localhost POSTs. |
| T-01-06 | Information Disclosure | shared error handler | medium | mitigate | Known stable client codes and generic unknown-failure response omit paths, stacks, request bodies, and settings values. |
</threat_model>
