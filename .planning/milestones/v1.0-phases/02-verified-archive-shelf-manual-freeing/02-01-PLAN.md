<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Metadata/recording annotation → archive writer | User-controlled Unicode text and recording selectors may influence stored JSON or file resolution. |
| Laptop library bytes → archive classifier | Manifests and included files can be malformed, replaced, truncated, or symlinked between operations. |
| Mounted/fixture source → laptop draft | Source identity and bytes must remain pinned while archive output is written only under the laptop library root. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `info.json`, `song.opz`, snippet, samplepacks | high | mitigate | Exact schema validation plus reread/hash/length/parse and manifest comparison before publication and every verified classification; tamper tests block the plan. |
| T-02-02 | Tampering / Information Disclosure | snippet path resolution | high | mitigate | Reuse canonical allowed recording roots, `realpathSync`, positive relative paths, regular-file checks, and symlink-escape tests before reading or copying. |
| T-02-03 | Information Disclosure | manifest and diagnostics | high | mitigate | Store only archive-relative paths and sanitized public provenance; bounded metadata projection and tests reject absolute roots, credentials, settings content, stacks, and raw errors. |
| T-02-04 | Elevation of Privilege | later HTML consumer | medium | mitigate | Keep metadata as bounded inert strings in the server response; Plan 02 escapes each value by HTML context and tests hostile markup rendering. |
| T-02-05 | Tampering | mounted/fixture source | high | mitigate | Preserve capture-once/final-source-revalidation and write only inside the hidden laptop draft; success and every injected failure compare source bytes unchanged. |
| T-02-06 | Spoofing | source fallback | high | mitigate | Archive creation remains pinned to one captured source and never re-resolves through `getSource()` after capture; source-substitution regression remains mandatory. |
| T-02-07 | Tampering | device-clearing surface | high | mitigate | Keep POST `/api/clear-slot` fenced and add no automatic-clear export or device mutation; full regression suite verifies the central route inventory. |
</threat_model>
